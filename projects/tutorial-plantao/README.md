# Tutorial · Plantão 24h

Vertical 1080x1920 tutorial for the office TV, about 5:00, silent. The 16:9 build is archived in `.hyperframes/backup/`. Walks the client app from the home screen to the pós-consulta inside an iPhone mockup: início e benefícios, plantão, pagamento Pix, anamnese, fila, consulta por vídeo, pós-consulta.

## How the UI gets here

The UI is not redrawn. The Expo app (`../../../vivamaisa-app`) runs on web from a copy in `../../.cache/app-web` with a few web-only shims (`capture/webcap/`: native-only modules stubbed, CanvasKit loaded for the Skia home gradient, `Text`/`Screen` web variants, Tailwind CSS compiled and injected, iPhone safe-area insets). `capture/` drives it in headless Chrome at 402x874 against a mock API (HTTP + the plantão websocket) and stores the rendered DOM of each state. `build/` scopes the captured CSS under `.vm-ph` and stamps the states into each chapter.

```bash
npm run app:setup         # once, or after the app changes: copy app + apply web shims
npm run capture:mock      # terminal 1: mock API + websocket on :8788
npm run app:web           # terminal 2: Expo web on :8095 (CLEAR=--clear after shim changes)
npm run capture           # all states; or: npm run capture -- home tutorial pay anamnese pos
npm run build
```

## Editing the video

- `build/scenes/*.mjs` — one file per chapter: title, tooltips, states, custom in-phone layers, choreography in `run(S)`
- `build/kit.js` / `build/kit.css` — camera, touch cursor, tooltips, native push/modal transitions, layers, bank phone Pix scan, verify ring, confetti
- `compositions/`, `index.html`, `ledger.json`, `STORYBOARD.md` — generated by `npm run build`, do not hand-edit

```bash
node build/preview.mjs ch03-pix 5,9,14,20 4   # contact sheet of one chapter
node build/fidelity.mjs home pos              # captured screenshot vs rebuilt DOM, side by side
npm run check
npm run seams
```

## Vertical + brand (2026-10-01)

- Kit runs in `portrait` mode (`VMKit({ portrait: { zoom, top } })`): the phone stays fully visible below a bubble band at the top; caption bubbles always render centered in that band.
- Chapter cuts use the signature "+" transition (violet Viva Mais "+" grows over the scene, the next chapter opens through a "+"-shaped window; `assets/brand/plus-solid.svg`). Cuts never dip opacity.
- Headlines use Space Grotesk; lime stays small (badges, dots, underline).
- `node build/audit-marks.mjs [ids]` checks every highlight against its target for its whole visible span; `python3 build/flicker.py <gray54x96.raw>` scores blinks in a render.
