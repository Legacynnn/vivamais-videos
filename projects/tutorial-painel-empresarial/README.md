# Tutorial · Painel Empresarial

Landscape 1920x1080 tutorial, about 3:30, silent, on-screen text. Walks the full company flow of `vivamais-web`: cadastro, painel, vidas, planilha, primeiro acesso, grupos, créditos, fatura, agendamento, consulta, relatório.

## How the UI gets here

The UI is not redrawn. `capture/` drives the real `vivamais-web` app in headless Chrome against a mock API and stores the rendered DOM of each screen state. `build/` scopes the app's compiled Tailwind CSS under `.vm-ui` (laptop, 1440x900) and `.vm-tab` (tablet, 1180x820) and stamps the states into each sub-composition.

```bash
# terminal 1: mock API on :8787 (fictional company Aurora Logística)
npm run capture:mock

# terminal 2: the web app pointed at the mock, from ../../../vivamais-web
NEXT_PUBLIC_REACT_APP_API='http://127.0.0.1:8787/' ./node_modules/.bin/next dev --turbopack -p 3457

# terminal 3: capture every state, then rebuild
npm run capture -- ch1 ch3 ch5 ch6 ch7 ch8 ch9 ch10 ch11
npm run build
```

`npm run capture -- <chapter>` recaptures one chapter; chapters ch6 to ch11 depend on the mock state left by the previous one, so run them in order.

## Editing the video

- `build/scenes/*.mjs` — one file per scene: text, states, and the choreography in `run(S)`
- `build/kit.js` / `build/kit.css` — camera, cursor, caption card, device frames
- `compositions/`, `index.html`, `ledger.json`, `STORYBOARD.md` — generated by `npm run build`, do not hand-edit

```bash
npm run build
node build/preview.mjs ch07-creditos 5,9,14,20 4   # quick contact sheet of one scene
npm run check
npm run seams
```

## Opening animation (Rive)

`rive/island.mjs` draws and animates the isometric company island through the Rive desktop MCP (`http://127.0.0.1:9791/mcp`, Rive app must be open with a file). It creates the `Intro` artboard in the open file, exports `.riv`, and `rive/render.mjs` renders it to `assets/intro/island.mp4`.

```bash
npm run intro
npm run build
```

Logo: use `assets/brand/wordmark.png` (transparent) and `assets/brand/mark.svg`. Never the gradient-background `logo-full.png`.
