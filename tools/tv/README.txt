VIVA MAIS TV

Start
  Double-click "Play TV.command".
  First time macOS may block it: right-click > Open > Open.
  Videos play fullscreen in order, then restart from the first, forever.

Browser
  Google Chrome installed -> true kiosk fullscreen, no clicks needed (recommended).
  No Chrome -> Safari. If macOS asks to let Terminal control the computer
  (Accessibility), allow it -> fullscreen is automatic next time.
  Otherwise click the screen once to go fullscreen.

Controls
  Right arrow   next video
  Left arrow    previous video
  Space         pause / resume
  Cmd+Q         stop (quits the player)

Screen never sleeps while the player is open.

Start automatically when the Mac turns on
  1. System Settings > Users & Groups > Automatically log in as: this user
  2. System Settings > General > Login Items > "+" > pick "Play TV.command"

Keep this folder together: index.html, Play TV.command and videos/ must stay side by side.
